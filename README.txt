PORTFÓLIO KARLA PINHEIRO — INSTRUÇÕES

1. Abra a pasta "portfolio-karla" no VS Code.
2. Os arquivos principais são:
   - index.html
   - style.css
   - script.js
3. As fotos estão em:
   assets/fotos/
4. Os vídeos estão em:
   assets/videos/
5. Os logos oficiais podem ser colocados em:
   assets/logos/

PARA TROCAR UMA FOTO:
Substitua o arquivo mantendo o mesmo nome ou altere o caminho no index.html.

PARA TROCAR UM VÍDEO:
Substitua o arquivo mantendo o mesmo nome ou altere o caminho no index.html.

PARA ALTERAR TEXTOS:
Abra index.html e procure o texto que deseja modificar.

PARA ABRIR:
No VS Code, instale a extensão "Live Server" e clique com o botão direito em index.html > Open with Live Server.

OBS:
Os três logos NESTLÉ, MAGGI e MÁGRASS estão inicialmente como tipografia no site. Quando você tiver os arquivos oficiais, coloque-os em assets/logos e podemos substituir por imagens/SVG.
